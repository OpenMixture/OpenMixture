## 有界问题与证据

[@1 契约](./mat-03-woven-surfaces.zh-CN.md)依据横向轮廓高度选择可见纱线。上层纱线边缘轮廓趋于零，下层纱线却仍抬高；选择局部更高者因而形成蝴蝶结。这是正确的 @1 行为。PR #87 的范围收窄提案已关闭未合并；单独收窄一个控制无法消除相互作用。已接受限制包括 plain 最小可见核心宽度 0.875、combined-high 约 0.42；原 432 点扫描中 156 点达到 0.75，crown=1 仅 8/144。阶段 B 记录了奇数尺寸平移 share 最多 27 个半精度步的敏感性。

用途仍限不透明平纹及不等轴变化；不含斜纹、织法目录、布料模拟、纤维几何或通用抗锯齿。目标为直边可见核心、连续抬升／下沉、圆冠、所有权切换处无高度台阶、与高度无关的覆盖、精确中心奇偶／分离、周期性，以及颜色／粗糙度／高度共享可见权重。几何连续性不等于人工视觉接受。

## 公共定义与采样

以下定义用于全部候选，保留 @1 坐标与控制。`F(t)=s²(3−2s)`，`s=clamp(t,0,1)`；奇偶使用欧几里得取余。UV 先经 fract 包裹，再设 `x=nw*u`、`y=nf*v`、`i=floor(x)`、`j=floor(y)`、`a=fract(x)−1/2`、`b=fract(y)−1/2`。

```text
Aw = F((ww/2 − |a|)/bevel)       Af = F((wf/2 − |b|)/bevel)
qw = max(1 − (2a/ww)^2, 0)       qf = max(1 − (2b/wf)^2, 0)
Tw = qw*(1−crown+crown*qw)        Tf = qf*(1−crown+crown*qf)
sx = F(fract(x−1/2))             sy = F(fract(y−1/2))
Lw = even(i+floor(y−1/2)) ? 1−sy : sy
Lf = even(j+floor(x−1/2)) ? sx : 1−sx
hw = Tw*(r+(1−r)*Lw)            hf = Tf*(r+(1−r)*Lf)
C = Aw + (1−Aw)*Af
Vw = Aw*(1−Af*(1−D))            Vf = C−Vw
```

其中 `r=underRatio`。@1 基线使用 `e=bevel*(1−r)`、`D=F((hw−hf+e)/(2e))`、`H=Vw*hw+Vf*hf`。每像素依序采样 `(p+(.25,.25))/size`、`(.75,.25)`、`(.25,.75)`、`(.75,.75)`；输出 height=`ΣH/4`、coverage=`ΣC/4`、warp-share=`ΣVw/ΣC`（ΣC=0 时为 0.5），不得平均各子采样的 share。归一化输出钳制，f32 运算，rgba16float `[value,0,0,1]` 存储。三个图实例须复制相同几何；relief 和 grain 仍由材质外部组合。

## 三种候选

### A — 中心线选择，保留加权高度

`D=F(1/2+Lw−Lf)`，`H=Vw*hw+Vf*hf`。固定 ramp 半宽为 lift 差单位的 0.5，无新增参数。选择不再依赖横向 crown 或 underRatio，但仍在重叠区域混合所有权。交叉中心 lift 差为 ±1，奇偶精确饱和；中心高度仍为 1 与 r。Ramp 与 lift 均为 C1；格边界处相关占用在纱线间隙恒为零，因此加权场也为 C1。有限 ramp 仍可能在纵向端部损失核心宽度，且被选上层表面可能低于下层。这是实验候选，并非推荐。

### B — 占用门控所有权，保留加权高度

定义只在未占用间隙过渡的带符号格信号：

```text
X = (even(i) ? 1 : −1) * F((1/2−|a|)/((1−ww)/2))
Y = (even(j) ? 1 : −1) * F((1/2−|b|)/((1−wf)/2))
D = (1+X*Y)/2
H = Vw*hw + Vf*hf
```

重叠处（Aw>0 且 Af>0）X/Y 精确为 ±1，所以整个占用宽度内 D 都是精确交叉奇偶。重叠之外 `∂Vw/∂D=Aw*Af=0`，D 不影响 Vw。求值时 `D=even(i+j)?1:0` 对 H/C/V 因而代数等价；提案定义的是上述 C1 间隙 ramp，不是可观察的硬切换。无新调参项。

所有权在分数占用合成之前选择。Aw<0.5 的羽化区域即便 D=1，背景纱线仍可能贡献更多 RGB。直边核心分数特意排除此抗锯齿边缘；是否接受此区分也是提案审查的一部分，并非声称每个非零覆盖像素都必须由红色占优。

格边界处 X/Y 及其一阶导数均趋于零，两侧一致；内部平台连接导数也为零。Aw/Af 为 C1，所以可见权重与加权高度为 C1，无所有权台阶。但只改所有权不能修复边缘实际高度次序：经线仍被选中时 hw 可能小于 hf。扫描中的下凹诊断将这种平滑凹谷与不连续区分。

### C — 占用门控所有权与连续叠层（推荐）

使用 B 的 D 和可见权重，抬高上层表面使其连续接入下层：

```text
经线上: Uw = Af*hf + (1−Af*hf)*hw; Uf = hf
纬线上: Uw = hw; Uf = Aw*hw + (1−Aw*hw)*hf
H = Vw*Uw + Vf*Uf
  = Zw + Zf − Zw*Zf, where Zw=Aw*hw, Zf=Af*hf
```

简式在所有权切换两侧及间隙完全相同；建议按简式求值，避免接近零时从一减去乘积的写法。高度和可见性都改变，必须使用 @2；不是只改颜色。颜色与粗糙度通过 coverage/share 使用相同 Vw/Vf；高度精确等于这些权重与调整后可见表面的组合。

下层完全占用时，上层在其支撑内部比下层高 `(1−lowerHeight)*upperProfileHeight`；上层轮廓趋零时接入下层。交叉中心上层精确为 1、下层 r，分离 `1−r≥0.25`；材质存储前分离为该值乘 relief。零 relief 仍精确为零；任意微小正 relief 下溢后不能保证存储半精度仍严格分离。保留 lift 与横向轮廓，但抬高支撑改变渲染凹陷／圆冠形状，须重新 PBR 评审。

### 连续性、周期性与精度比较

crown<1 时 Tw/Tf 本身在支撑边缘存在导数折角；乘占用后没有：占用在那里二次趋零，所以 Zw/Zf 及其一阶导数均趋零。A/B 的各可见高度项也带这些因子。C 是 Zw/Zf 的多项式，因此跨支撑边缘与所有权切换为 C1。纱线中心绝对值尖点被占用平台隐藏；Tw/Tf 是光滑偶函数。Lift 连接使用端点导数为零的 F。偶数计数让符号、lift 与场整瓦片重复；相对边界 texel 是不同采样，不是相等探针。盒滤波保持解析连续性与周期性，半精度量化不保持可微性。

@1 选择器对高度差的导数上界为 `0.75/[bevel*(1−r)]`（最小 e 时为 150）。A 对 lift 差的导数上界为 1.5。B/C 完全移除可观察权重中的该项，剩余占用斜率每 UV 轴上界 `1.5*n/bevel`。间隙选择器斜率可能大，但乘以零重叠。C 的 `∂H/∂Zw=1−Zf`、`∂H/∂Zf=1−Zw` 都在 [0,1]。这些并不证明奇数尺寸平移 f32 坐标逐位一致，也不消除通常的半精度存储变化。S 仍除以覆盖；P=S*C 才是可观察量，空白处 S 不可观察。

## 拟议公开契约与 ABI

待维护者审查：**`weave-pattern@2`**，无输入，单个 Scalar `value` 输出。保留 `mode` 枚举 `height`（默认）、`coverage`、`warp-share`，三实例几何一致。所有参数名／类型／范围／默认值保持 NODE @1 契约（不是材质默认值）：

| 参数 | 类型／闭区间 | 节点默认值 |
|---|---|---|
| warpCount、weftCount | Integer，偶数 4..32 | 8、8 |
| warpWidth、weftWidth | Float .55.. .9 | .7、.7 |
| bevel | Float .02.. .12 | .08 |
| crown | Float 0..1 | .5 |
| underRatio | Float .25.. .75 | .5 |
| mode | 上述 Enum | height |

无新控制、种子或随机性；外部 fractal grain 仍须显式种子。奇数计数必须拒绝而不是舍入；类型／范围／枚举错误用带节点／参数身份的 `MIX_PARAMETER_INVALID_VALUE`，未知键用 `MIX_PARAMETER_UNKNOWN`。Bevel 仍设置占用羽化宽度，但不再设置深度选择陡度；underRatio 保留中心线 lift 意义，不控制可见性。边缘含义改变属于明确的 @2 语义。

保留 48 字节 uniform 草案：0..15 字节 u32 `[warpCount,weftCount,mode,0]`，height=0／coverage=1／share=2；16..31 字节 f32 `[warpWidth,weftWidth,bevel,crown]`；32..47 字节 f32 `[underRatio,0,0,0]`；padding 全零。相同 8×8 dispatch 及 scalar rgba16float 绑定约定。不新增 ABI 大小、多输出编译器功能或公开原始输出 API。固定确定求值顺序、精确身份、有限归一化存储；跨驱动舍入仍须实测 Native/browser ≤1/255 验收。

## 目录、版本与材质影响

建议在**后续实现 PR**新增独立 `KernelId::WeavePatternV2`／typed invocation 和仅一个 @2 WGSL，保留 @1 shader 字节与 lowering。当前 registry `BUILT_INS` 是 18 类最新契约列表，`node_contract_version` 另外保留 noise@1。@2 保持 **18 类最新类型**，将最新 weave 指向版本 2 并保留显式 weave@1 查找：**支持的类型／版本身份 19→20**，**kernel 16→17**。显式审查身份测试须覆盖两个 weave 版本，仅测计数不够。这只是提案，本 PR 不改目录。

建议下一未发布候选 **Rust 0.10.0／browser 0.10.0-alpha.0**。当前未发布 0.9 已绑定接受回执，新 kernel／invocation 变体影响 Rust 穷尽匹配并产生新像素；独立的 1.0 前 minor 候选明确兼容边界，即便格式不变。`.mix`／`.mixpack` v1 与 plan／browser API v3 不变。旧 runtime 拒绝显式 weave@2；新 runtime 对旧 weave@1 文档保持相同渲染。不自动迁移，不修改 manifest，不发布。

未来织物配方修订须显式将三个结构实例改用 @2，保留修订 2 字节，并为改变的 height/share 像素重新验收 MAT-03 **A–D**：公开 Native/browser 矩阵与预算；结构／控制／周期／法线重放（含重新审查的数值条件规则）；生产者绑定的介电 PBR 图及独立人工决定；保留证据与接受。提案算术变化不增加图节点或 pass；同拓扑意味着描述符分配预计不变，但 @2 pass／峰值／耗时**未实测**。现有接受仍只覆盖 @1 记录范围。
