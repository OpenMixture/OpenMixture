# M6B-03 CPU 验证

[English](./README.md) | 简体中文

[PR #43](https://github.com/OpenMixture/OpenMixture/pull/43)在 M6B-02 基础上实现共享 CPU codec。[verification.json](./verification.json)将最终干净工作区本地运行绑定至 **162456342e1f9bb2ee82675cfcc9c6458657fb1b**、源码树、锁文件、小型语料、工具链与包验证器。后续证据/文档提交不冒充已测试的运行时提交。

Windows x86_64、Rust/Cargo 1.98.1 上 `cargo xtask check` 通过，包含全部工作区测试、Clippy、独立源码/CLI 消费、四归档隔离消费、Rustdoc 和链接。asset crate 包含四个单元测试、七个集成测试和一个文档测试；语料共 22 项。公共 Native 资产测试在源码路径与解包归档上均通过。codec WASM 编译与全部 12 个候选/消费者 Node 测试通过。标准 tar 读取器列出的合法归档与写入器逐字节复现的归档相同。

测试验证借用载荷指针范围、所有权转移时指针不变、独立不可变快照，以及精确计费减少一字节后的拒绝。计数包含保守 D+M 临时预算。这是字节缓冲账本，不是 RSS 或全局多资产上限。fixture/源码与此前 Python 格式探针不同，应比较所有权公式，不能要求不同输入的归档尺寸相等。

复现见[实现指南](../../m6b-03-cpu-assets.zh-CN.md)。回执留存包哈希、固定依赖数、源码/解包不变性及删除 shader 的负例结果。完整日志和本地 `.crate` 文件仅临时保留于记录的忽略路径，哈希不保证未来可取回。Git 留存代码、聚焦输入/测试、简洁回执和说明。不声称包 GPU/浏览器验收、版本发布、视觉基线变化或更广硬件支持。远端 CI 与本地回执分开记录。
