# ADR 0006：有界的浏览器纹理一致性

[English](./0006-browser-quality-gates.md) | 简体中文

状态：2026-09-20，已通过 PR #19 接受。用户授权的收口移除已替代诊断，并将相同冻结质量规则用于浏览器运行时和 Studio 材质比较。原生软件金图、精确棋盘格检查和节点语义不变。未采用的 warp 提案作为研究关闭，不再是发布前置条件。

## 背景

旧浏览器规则将任何分量变化计为变化像素，仅允许极稀疏差异。它能发现数值差异，却混淆了差异分布范围与材质损害。广泛且平衡的单级残差可能失败，即使每个像素都满足相同的幅度约束。需要保留对偏移与局部缺陷的敏感性，同时避免将接近逐字节一致作为普遍浏览器要求。

## 决策

采用版本化的 [v2 规则](../browser-quality-v2.json)和[测量契约](../browser-quality.zh-CN.md)。保持 RGB 最大差值为一个编码 RGBA8 单位，取消变化像素比例和全图平均误差作为接受条件。用重叠且循环的窗口测量有方向的连贯偏移，增加法线方向/响应、高度梯度、粗糙度响应检查。当前报告不再计算已替代的稀疏像素判定。原结果仍可从 Git 历史查阅；不将历史失败改写为通过。

计划、来源、编码、全部 11 案例/4 通道、已有材质结构/接缝/因果/关系检查、生命周期、安装与生产部署继续强制执行。新规则是工程一致性预算，不是普遍感知阈值、精确浮点契约或接受一切浏览器差异的许可。Native 是固定同源比较参照，不是数学真值；有争议的结果仍须独立标量诊断，禁止为通过而更换参照。

先通过独立合成扰动控制，再冻结规则与实现，之后才应用于浏览器输出。禁止按浏览器结果拟合。后续规则修订须有新标识、理由、控制案例和冻结记录，保留先前全部结果。

## 替代方案

普遍字节一致超出产品承诺。仅扩大变化像素数量仍不能区分空间上连贯的偏移；全局平均误差可能掩盖局部缺陷；仅感知图像分数可能漏掉下游高度/法线错误；按浏览器分别挑参照可能掩盖分歧。所选规则结合严格幅度上限、空间与输出用途测量，不声称能检测所有无害或有害变化。

## 后果与迁移

浏览器报告 schema 3 绑定完整规则及摘要，分别报告语义、结构和数值结果；Studio 报告 schema 2 绑定同一质量规则及不变的保存文件标准。当前资格验证拒绝旧报告、缺失或失败的当前门槛。测量模式不能认证包。旧报告仅代表其原始执行，不可替代新资格。`.mix`、节点、RenderPlan、运行时 API 和包版本不变。

历史 PNG 只能在新证据目录中重新评估，标为回溯分析并保留原源码/环境身份；不算新浏览器执行。新包资格仍须独立安装及实际浏览器执行。规则调整不代表采用着色器实验或新金图。

## 验证

`cargo xtask browser-quality-calibrate <fresh-output>` 不读取浏览器输入，生成 40 项确定性正负控制及可审查对照图。聚焦 Rust 测试独立检查几何、响应公式、局部偏移及编码拒绝；JavaScript 测试拒绝过期或缺失的规则证据。运行 `cargo xtask check`、当前候选浏览器 CI，以及冻结后对保留普通浏览器输出的比较。失败继续如实记录。宣称 v2 支持前检查实际材质对比并说明局限。

停止条件是在明确记录的用途范围内全部必要 v2 门槛通过，且不存在未解释的结构缺陷。结构变化、更大误差、连贯偏移或响应检查失败仍须诊断。通过本预算不认证任意世界空间位移尺度或全部下游 BRDF/光照。
