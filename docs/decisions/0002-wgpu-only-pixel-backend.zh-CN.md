# ADR 0002：wgpu 是唯一像素后端

[English](./0002-wgpu-only-pixel-backend.md) | 简体中文

状态：M0 基础工程已接受。来源：[架构第 7、9 节](../../ARCHITECTURE.zh-CN.md)。

## 背景

同时维护 CPU、WebGL 和原生 GPU 像素实现，会成倍增加节点工作，并削弱视觉一致性。

## 决策

全部像素由 `mixture-wgpu` 中的 `wgpu` 计算着色器执行，每个生成像素的内核恰好对应一份 WGSL 实现。M0 不引入 GPU 依赖。M1 在图工作开始前证明无界面执行和回读可用。

## 备选方案

CPU 参考渲染器会复制像素语义。独立的 TypeScript/WebGL 执行器会重复实现和集成工作。固定版本的软件 GPU 适配器可以直接验证实际 WGSL 路径。

## 影响

不得引入 CPU 像素正确性参照实现或第二个渲染器。原生与浏览器 API 可以在统一 `wgpu` 执行模型内选择不同适配器。必要时，跨适配器像素测试使用文档规定的容差。

## 迁移

不移植旧渲染器作为兼容后端。节点内核契约和着色器按初始 PR 顺序，以完整的专项纵向实现逐步加入。

## 验证

M0 检查确保没有 GPU 依赖或额外产品 crate。M1 添加计算／回读冒烟证据；后续节点和材质检查在固定软件适配器与真实硬件上验证同一套着色器。
