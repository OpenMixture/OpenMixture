# ADR 0003：.mix v1 是单个可读 DAG

[English](./0003-readable-mix-dag.md) | 简体中文

状态：M0 基础工程已接受。来源：[架构第 5–8 节](../../ARCHITECTURE.zh-CN.md)。

## 背景

首版材质格式必须可检查、具有确定性、资源有界，并在没有编辑器时仍然有用。在出现使用方证据之前引入二进制容器或嵌套图系统，会过早增加复杂度。

## 决策

使用带版本的 UTF-8 JSON，包含单个有向无环图：稳定节点 ID、节点类型／版本、强类型参数、边和暴露绑定。材质语义与编辑器布局、缩略图、预设、目标引擎配置、资源和自定义着色器分离。M2 定义解码和可执行 schema 行为。

## 备选方案

二进制 `.mixar` 格式不便人工检查。内嵌编辑器状态会将运行时资产与产品 UI 耦合。子图会在初期引入不必要的编译和迁移复杂度。

## 影响

验证必须拒绝未知或不支持的语义、环、非有限参数和预算违规。遍历和序列化顺序稳定，随机节点必须提供种子，不静默修复图。

## 迁移

不静默重新解释旧格式。未来变更需声明属于增量扩展、可迁移变更还是破坏性变更；语义变化必须进行版本管理。M0 不创建占位 `.mix` 夹具。

## 验证

M0 文档检查保证契约可发现。在声明支持格式之前，M2 添加解码、拒绝输入、往返转换、图、预算和确定性计划测试。
