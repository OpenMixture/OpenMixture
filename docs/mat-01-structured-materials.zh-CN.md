状态：MAT-01a 实现契约，2026-09-23。这是[材质路线图](../ROADMAP.zh-CN.md)下选定的有界设计，不代表新节点或材质像素已经实现、接受。MAT-01b/c 负责实现，MAT-01d 记录验收源码与评审。发布继续独立处理。

## 材质目标与审查后的目录增量

制作无缝、参数化的矩形烧制黏土砖与铺地砖材质族。视觉目标是逐块变化、清晰的凹陷灰缝、软化砖边，以及一致的 baseColor、roughness、height 和 normal。须同时表达规则铺地和交替错行砖墙。不包含破损石块生成器、照片重建或模型位移渲染器。

选定两个新增类型／版本身份：`brick-pattern@1`（MAT-01b）与 `scalar-mask-blend@1`（MAT-01c）。现有身份不变。完成后目录为十五种类型、十三种内核；最新 v2 契约之外继续支持 `fractal-noise@1`。这些数量描述本次增量，不是后续准入上限。有界砖块生成器直接拥有重复矩形轮廓，本用例无需通用形状／散布系统。第二个节点提供可复用空间 Scalar 组合，不改变统一权重的 `scalar-blend@1`。

Core 负责两个契约、全图验证、覆盖验证、类型化降级及计划身份。每个新增内核在 wgpu 中只有一个 WGSL 实现。公开注册表继续作为浏览器元数据来源，绑定和 CLI 不重复节点语义。无需新增 crate 或外部资源格式。

## brick-pattern@1

无输入；一个 `value: Scalar` 输出。所有参数可公开暴露。即使 variation 为零或节点在未使用分支上，也必须显式提供无符号 `seed`。

| 参数 | 类型／含端点范围 | 默认值 |
|---|---|---|
| `seed` | Integer 0..4294967295 | 必填 |
| `columns` | Integer 1..64 | 8 |
| `rows` | Integer 1..64 | 8 |
| `rowOffset` | Float 0..1，以单元宽度为单位 | 0.5 |
| `mortarX` | Float 0..0.45，水平间隙占单元宽度的比例 | 0.08 |
| `mortarY` | Float 0..0.45，垂直间隙占单元高度的比例 | 0.08 |
| `bevel` | Float 0..0.25，以单元坐标为单位的向内轮廓宽度 | 0.08 |
| `variation` | Float 0..1，独立逐单元幅度变化 | 0.15 |

非零 `rowOffset` 要求 `rows` 为偶数，覆盖参数后也如此。违反时返回 `MIX_PARAMETER_INVALID_VALUE`，带节点 ID 和 `rows` 参数上下文；不得取整 rows 或静默关闭偏移。这保证垂直平铺边界的交替行相位。单行、无偏移是合法情况。

坐标原点位于左上，v 向下。每个纹素在像素足迹内偏移 `(0.25,0.25)`、`(0.75,0.25)`、`(0.25,0.75)`、`(0.75,0.75)`，除以输出尺寸后进行四次求值并平均。固定 2×2 盒式采样属于 v1 语义，不是通用抗锯齿保证。

每次求值计算 `y = v * rows`、`row = floor(y)`、`x = u * columns - (row % 2) * rowOffset`。令 `local = (fract(x), fract(y))`，将 `floor(x)` 按 columns 取循环模得到单元身份。向内距离为

`d = min((1-mortarX)/2 - abs(local.x-0.5), (1-mortarY)/2 - abs(local.y-0.5))`。

`d <= 0` 时轮廓为零；否则 bevel 为零时为一，非零时令 `t = clamp(d/bevel, 0, 1)`，轮廓为 `t*t*(3-2*t)`。Bevel 相对于单元坐标轴，因此矩形单元两轴的物理倒角宽度可以不同。这是明确限制，不隐式换算物理单位。

单元随机值使用循环 u32 算术。定义 `H(z)` 为 `z ^= z >> 16; z *= 0x7feb352d; z ^= z >> 15; z *= 0x846ca68b; z ^= z >> 16`。令 `h = H(seed ^ H(column) ^ H(row + 0x9e3779b9))`、`r = (h >> 20) / 4096`。12 位随机分数可由 f32 精确表示。每个样本返回 `profile * (1 - variation*r)`；四样本平均值按 `[value,0,0,1]` 存入 rgba16float。f32 轮廓求值与 f16 存储仍受冻结的跨端门槛约束；随机身份一致不单独证明法线一致。

改变种子只影响幅度，不影响单元布局或间隙宽度。多个图案节点使用相同布局／种子参数即可对齐。variation 为零时生成轮廓／遮罩；高度与着色可使用独立 variation。生成器返回归一化起伏，不是物理高度。已有 levels 和 height-to-normal 设置最终尺度及法线强度。`mortarX=mortarY=bevel=variation=0` 不保证在精确单元边界上返回一，仍适用明确的 `d <= 0` 规则。

## scalar-mask-blend@1

必需输入 `a: Scalar`、`b: Scalar`、`mask: Scalar`，输出 `value: Scalar`。一个 Float 参数 `opacity`，范围 [0,1]，默认 1。将有限输入样本限制到 [0,1]；令 `t=opacity*clamp(mask,0,1)`。t=0 时返回精确的已限制 a，t=1 时返回 b，否则返回 `clamp(a+(b-a)*t,0,1)`。以 `[value,0,0,1]` 存入 rgba16float。无重采样、alpha／颜色转换或新随机状态。端点情况下仍须提供、验证三个输入。周期性继承输入，不修复接缝。

该节点让砖轮廓将表面粗糙度或起伏放到灰缝背景上。颜色组合继续使用已有带遮罩 `blend`，法线从最终组合高度派生。新通用运算、AO、法线混合或形态节点不是 MAT-01 前置，MAT-02 决定其实际必要性。

## 兼容性与资源边界

`.mix v1`、plan/hash v2、API schema 2 和 `.mixpack v1` 不变。新增类型化内核变体对序列化计划是增量，但对 Rust 穷举匹配存在源码破坏，因此首次运行时实现将未发布候选推进至 Rust 0.6.0 / browser 0.6.0-alpha.0。已有序列化变体及旧计划哈希必须不变。旧运行时明确拒绝新类型身份，现有文档／资产不自动迁移。已发布 browser 0.3.0 归档保持不可变。独立消费者与固定可丢弃宿主元数据断言仅针对有意的版本／目录增量更新，保留全部行为检查。

计划中的砖块 uniform 为 48 字节：四个 u32 `[columns,rows,seed,0]`，随后 f32 `[rowOffset,mortarX,mortarY,bevel]`、`[variation,0,0,0]`。遮罩混合使用 16 字节 `[opacity,0,0,0]`。两者复用 8×8 dispatch 和已有输出尺寸的 rgba16float 中间纹理，不需要额外纹理、回读或上传。在当前保留所有纹理的调度下，四通道材质最多使用 12 个计算 pass，2048² 估算／记录的描述符峰值低于 448 MiB。CPU 与包缓冲区继续采用独立策略，不提高全局限制以使夹具通过。

## 冻结验收矩阵

[qualification-plan.json](../fixtures/materials/brick-paving/qualification-plan.json) 是后续验证器的机器可读用例／预算输入，包含计划门槛，不是测试结果。独立修改 columns、rows、两个 mortar 宽度、rowOffset、bevel、高度／颜色 variation 和 seed；预设不能替代因果测试。验证器须检查预期方向／局部性，而非仅检查哈希变化。

- 在 256²、1024²、2048²、257×129 渲染四通道。固定规则、错行、随机变化和第二种子用例都须通过。另测试 1×1、1×17、17×1 节点输出、完整 u32 种子、合法参数端点、零 variation，以及在 GPU 获取前拒绝非法奇数错行。
- 固定 SwiftShader 上相同输入重复渲染须逐字节一致。Native／浏览器各通道 RGBA8 分量最大绝对误差 ≤1，包括 normal。可用时明确测试已记录 GT 1030 Vulkan／DX12 与浏览器比较，不声明其他硬件。失败需调查，不得静默扩大本契约门槛。
- 结构探针采用解析选定且远离滤波边界的内部／间隙样本点：间隙高度为零、砖内部为正、指定行相位、倒角前单元内部常值、种子间布局稳定、随机变化可复现。间隙加宽减少占用面积；bevel 增大降低边缘起伏但不改变单元身份。零 variation 消除种子影响，遮罩端点精确复现直接输入。
- 接缝探针使用生产内核探针中仅供测试的采样原点，对比周期偏移渲染与未偏移结果的对应循环移动，并配合平铺对照图。这不是第二渲染器，也不能成为无版本的公开参数。相对边界字节对应不同样本，不要求相等。
- 对固定默认材质，将 256² 输出与盒式降采样的 1024² height/baseColor 比较，各通道平均绝对误差 ≤4/255。在 256² 对 64×64 单元施压；保留混叠实测结果，若相同指标失败，将该设置标为默认质量保证之外。法线按分辨率派生，不按颜色降采样方式比较。不自动放宽门槛。
- 固定 PBR 证据使用平面和球体，各预设保持相同中性照明／相机／材质尺度，包含 1×、3×3 平铺及通道近景。依证据策略保留图像与真实人工评审决定；自动检查不得虚构人工接受。
- 在同一显式 renderer 中测量一次冷渲染和五次热渲染（热墙钟中位数，包含回读；可用时记录 GPU 时间）。1024² 下 GT 1030 预算为冷 5 s／热 500 ms，固定软件为 30 s／10 s。2048² 热预算为硬件 2 s／软件 40 s。记录确切宿主／后端；这是阶段目标，不是已发布 SLA。失败启动 PERF-MAT 测量及单独审查的优化，不提高预算。

MAT-01d 需要定向 CPU 和着色器／节点检查、新材质门槛、原始与迁移后的已有材质矩阵、Native／浏览器公开候选消费、保留源码及结果计划／像素的包往返、`cargo xtask check`、全部六项必需 CI 及留存评审内容。使用新证据目录。新节点／材质命令只有在实现和测试入口落地后才可执行，本契约不声称它们已可用。
