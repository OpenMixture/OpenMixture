# 浏览器纹理一致性：v2 规则

[English](./browser-quality.md) | 简体中文

[决策](./decisions/0006-browser-quality-gates.zh-CN.md)适用于 `browser-material-check` 与 `browser-material-measure`，只测量已渲染纹理，不增加像素执行器。[JSON 规则](./browser-quality-v2.json)与比较器共同版本化，当前资格收据必须标识其确切字节。历史 [M5-05 校准](./evidence/m5-05/calibration.zh-CN.md)和 `browser-tolerances.json` 保持不变，用于旧门槛诊断。原生金图及 Studio 独立的保存文件比较器保持不变。

## 预算与用途

| 测量 | 冻结工程限制 | 理由与范围 |
|---|---|---|
| RGB 编码最大差值 | 1 字节级 | 保留旧幅度上限；平衡量化残差的密度本身不再导致失败 |
| 局部窗口 RGB 有符号均值的绝对最大值 | 0.25 字节级 | 16×16 邻域每分量最多累计 64 个有符号码值；检测连贯单级偏移，避免全图平均掩盖问题 |
| 窗口 | 16×16，步长 8，循环寻址 | 重叠避免只检查不重叠网格，循环窗口也检查边界；不保证检测所有更小空间模式 |
| Alpha 与标量编码 | 两图 Alpha 均为 255；高度/粗糙度 R=G=B | 编码不属于浮点容差 |
| 法线方向 | 最大 1 度 | 比较解码并归一化的切线空间向量；近单位法线每 RGB 分量变化一码值带来亚度级扰动；这是保守工程预算，不是视觉可辨阈值 |
| 法线长度变化 | 0.02 | 检测额外编码向量畸变；已有绝对法线/高度关系检查继续有效 |
| 法线方向响应 | 漫反射最大 0.02，高光最大 0.08 | 五个固定上半球方向；漫反射为 `max(dot(n,l),0)`，高光为其 64 次方；仅为采样敏感性，不是完整材质渲染器 |
| 高度一阶差分误差 | 每 texel 最大 2/255，包括循环边界 | 两个端点各可差 1/255；报告向斜率传播的误差，不暗示物理位移尺度 |
| 粗糙度响应 | 峰值归一化 GGX 截面最大差 0.05 | 检查高光形状敏感性，特别是低粗糙度；alpha=r²，r 下限 0.04，八个固定余弦采样点，定义见实现 |

预算来自输出量化及明确的工程响应约束，不按当前浏览器残差拟合，也不是感知认证。法线/粗糙度响应采样不能复现消费者完整 BRDF；异常尖锐光照或物理位移需要额外消费测试。颜色仍在编码 sRGB 单位比较，保留严格的单级幅度上限，不是 CIE 感知指标。窗口以下的模式及未采样光照可能避开这些响应采样，因此已有结构、接缝和因果检查继续强制执行。

## 控制案例与冻结

使用新输出目录运行 `cargo xtask browser-quality-calibrate tmp/quality-controls`。每通道的恒等、广泛平衡 ±1 码值和单个稀疏 +1 码值应通过。整体偏移、16×16 偏移块、跨循环边界偏移块、八像素接缝条带、孤立两级尖峰、八级细节抹除和错误 Alpha 应失败。命令生成 40 张原图/扰动/差异对照图及 `calibration.json`；其中 `ok` 表示符合预先规定的标签，不表示所有扰动图都通过。

单元测试另含独立解析案例和编码/法线检查。先审查控制案例并冻结源码/规则身份，再评估浏览器；不能看完浏览器报告后调失败阈值。比较器有缺陷时必须修正、记录版本并重跑控制，再开始新一轮评估。

## 报告与停止条件

报告 schema 2 包含 `profile`、`profileSha256` 及 `gates`：`semantics`、`materialStructure`、`numericalAgreement`、`legacyPixelRegression`。每通道 `comparison` 为 v2 指标，`legacyComparison` 保留原幅度/平均/变化像素指标及原判定。接受要求全矩阵前三项门槛通过；旧门槛失败继续显示，但不覆盖它们。`measurement only` 只保留测量，不接受数值一致性，包资格验证会拒绝它。

运行时获取/执行失败继续作为结构化失败，和比较结果分开。输入为历史记录时，完成矩阵和通过响应预算不代表新浏览器执行。回溯比较应在新目录使用副本并绑定原 PNG/收据/源码身份。新的浏览器支持声明仍需安装候选、实际普通配置执行、全部已有生命周期/失败测试和适当范围的视觉审查。

当记录范围内所有必要门槛通过，且差异没有未解释的结构后果时，停止追逐末位对齐。幅度、偏移、响应或语义门槛失败时继续诊断。固定源码/参照，不能通过选择另一 Native 实现获得通过。

GGX 分布与 alpha=r² 约定参考 [Filament 材质模型](https://google.github.io/filament/main/filament.html)；本文的峰值归一化、采样点、下限与误差预算是本项目的诊断选择，不是 Filament 接受标准。
