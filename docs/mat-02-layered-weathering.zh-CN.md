# MAT-02 — 分层涂漆金属（契约草案）

[English](./mat-02-layered-weathering.md) | 简体中文

状态：前期设计，2026-09-23。MAT-01 已通过留存机器与人工证据满足退出条件；下一步为 MAT-02a 契约。本文依据[材质路线图](../ROADMAP.zh-CN.md)准备 MAT-02，不接受新的目录身份、不启动运行时实现、不关闭 MAT-01，也不发布包。节点实现之前须解决待定决策并冻结可执行验收计划。

## 材质与缺失操作

制作无缝的涂漆金属材质族，包含完整涂层、裸露金属及集中于掉漆边界的锈迹。同一组遮罩必须驱动 baseColor、metallic、roughness 及最终 height/normal。视觉目标包括凸起涂层、凹陷露底、独立可调的破损边缘宽度与锈量，以及显式种子控制的可复现表面变化。不包含物理腐蚀、依赖模型的边缘磨损或烘焙系统。

现有目录已有 `fractal-noise@2` value noise、`levels@1`、带遮罩的颜色 `blend@1`、`scalar-mask-blend@1`、常量及 height-to-normal。它们能重映射、反转、相乘和组合归一化场，无需引入通用数学库：a 与 m 相乘可用 `scalar-mask-blend(a=0,b=a,mask=m)`。从最终高度生成法线，无需新增法线组合节点。

缺失的是邻域最小值／最大值操作：现有逐点重映射无法按指定空间距离腐蚀遮罩。Warp 重新定位采样，不提供腐蚀／膨胀契约。掉漆边缘带需要保留原遮罩并减去腐蚀后的内部；只改变噪声阈值并不是独立的边缘宽度控制。

## 提议的 scalar-morphology@1

一个必需的 `in: Scalar` 输入和一个 `value: Scalar` 输出，无随机状态。提议参数：

| 参数 | 类型／范围 | 默认值 |
|---|---|---|
| `operation` | 枚举 `erode`、`dilate` | `erode` |
| `axis` | 枚举 `x`、`y` | `x` |
| `radius` | 整数 0..16，单位为输出纹素 | 2 |

对整数像素 p，沿指定轴读取 [-radius,+radius] 内每个整数偏移 k 的红分量。坐标按对应轴尺寸取模环绕，包括尺寸小于核的情形。将有限样本夹到 [0,1]，腐蚀取最小值，膨胀取最大值，包含中心样本。以 rgba16float 存储 `[value,0,0,1]`。半径为零时对归一化输入精确恒等。不插值、不平均、不使用隐藏纹理采样器，也不引入 CPU 像素执行器。

相同半径的 x 实例接 y 实例形成正方形切比雪夫邻域，不是欧氏圆盘、距离变换或模糊。相同矩形核交换轴顺序结果等价。细特征可能在腐蚀后消失，这是规定行为。单像素轴与重复环绕样本仍有效。有限值／范围检查及精确解析探针须覆盖这些情况。

半径明确采用离散纹素数。夹具消费者把公开参考宽度（1024 分辨率下 0..8 纹素）分别映射到每个轴，使用整数最近舍入 `floor((referenceWidth * axisLength + 512) / 1024)`，非零参考宽度至少映射为一。计划矩阵的各轴不超过 2048，因此映射半径不超过 16。这属于显式夹具请求构造，不是隐藏节点语义。超出节点范围时拒绝，不夹值。正方形图像两轴半径相等；矩形输出独立映射 x/y 半径以保持归一化轴宽度。分辨率舍入是明确限制，须在小尺寸／奇数尺寸测试。

Core 拥有契约、验证、类型化内核参数及哈希。wgpu 拥有唯一实现及 16 字节 u32 uniform `[operation,axis,radius,0]`，判别值须文档化。每个实例使用一次 8x8 compute dispatch 和一个现有 rgba16float 中间纹理；二维形态处理使用两个普通图节点。不新增 crate、隐式资源查找、执行器或隐藏多 pass 节点。

## 提议的 scalar-subtract@1

必需输入 `a: Scalar`、`b: Scalar`，输出 `value: Scalar`，无参数及随机状态。对有限样本，分别夹到 [0,1]，再返回 `max(a-b,0)`，以 rgba16float 存储 `[value,0,0,1]`。相等输入精确为零；b=0 保持归一化 a；a<=b 时为零。这是饱和减法，不是有符号运算或绝对差。Core 负责契约／降级，wgpu 提供一个逐点 WGSL 内核，沿用已有空参数 uniform 约定。

第二个候选由内部边缘带 W-I 的需要驱动。零端点遮罩插值计算 W*(1-I)，当 W=I=0.5 时，即使腐蚀半径为零也错误地产生 0.25。精确算术下可用三个现有节点合成减法：反转 b，以 0.5 权重混合 a 和反转值，再把 [0.5,1] 重映射为 [0,1]。但中间半精度存储可能抹去边缘带：对可精确表示的 a=0.5、b=0.499755859375，反转值舍入成 0.5，组合结果为零，而一次减法保留 0.000244140625。这个算术反例支持单 pass 契约，但不是 GPU 验收。[留存的干净源码 CLI 复现](./evidence/mat-02-subtraction/README.zh-CN.md)在记录的 Vulkan／DX12 适配器上确认了此组合损失，支持准入决策，但不接受新内核或材质。测试须包含相等的小数场、端点、次序、可精确半精度表示的差值及周期输入。不能以该乘积代替减法，也不增加无关算术模式。两个提议身份都须在 MAT-02a 评审后才准入。

## 组合与控制

用带种子的低频 value noise 重映射为露底遮罩 W。沿 x/y 腐蚀得到 I。掉漆边缘带为 `B=max(W-I,0)`，使用提议的饱和减法。零半径时 B 精确为零，包括小数 W。锈迹覆盖 R 由 B 与显式锈量调制，仅在视觉需要时再加入独立种子的第二个 value-noise 场。构造上保持 `0<=R<=W<=1`。露底区域完全生锈是独立预设／向 W 的显式混合，不能意外改变边缘遮罩。

基础颜色先用 W 混合涂层／底材，再用 R 混合锈色。选定的涂层／铁锈为介电质、底材为金属，因此 metallic 为 `W*(1-R)`。粗糙度使用同一组遮罩及固定、不同的涂层／底材／锈迹端点。高度使涂层高于底材，并可在 R 内抬升锈迹；法线始终由最终高度生成。仅颜色控制不得影响高度、法线、金属度或粗糙度。锈色不能改变覆盖范围，表面细节幅度不能移动宏观露底边界。

公开概念控制包括露底量、露底尺度、显式宏观／细节种子、破损边缘宽度、锈量、涂层／底材／锈迹颜色、三者粗糙度、漆层厚度、锈迹浮雕和法线强度。在 MAT-04 之前，它们仍由调用方映射到参数。除已证明的邻域及饱和减法缺口外，优先使用现有目录。AO、曲率、模糊、额外 Scalar 运算、材质层类型及新法线混合都须另有实际失败才准入。

## 实现之前冻结的验收

机器可读计划必须规定精确预设、种子、端点、采样位置、容差及请求映射；不能在看见失败后放宽以下要求。

- 预设：默认掉漆、完整涂层（W=0）、干净裸露底材（W=1,R=0）、生锈裸露底材（W=1,R=1）、边缘锈迹、不同宏观种子及不同细节种子。五个材质通道均在 256²、1024²、2048² 和 257x129 渲染。关闭细节时，端点预设须解析地复现对应常量材质及中性法线。
- 节点探针：半径 0/1/16、两种操作／轴、1x1/1x17/17x1 和奇数矩形、常量场、脉冲、细线、居中矩形及跨周期边界特征。断言精确内部值及受影响像素集合、min<=input<=max、随半径的单调性、x/y 组合等价和周期平移等价。允许测试中的独立 Scalar 期望值断言，不引入 CPU 渲染 API 或回退。
- 因果：增加边缘宽度扩大 B，但不改变 W；零宽度时 B 精确为零，即使 W 为小数；锈量改变 R，但不改变 W/I；种子变化可复现；数量端点精确；颜色变化仅影响 baseColor。在真实材质上检查 `R<=W`、金属度及粗糙度关系、高度次序和法线一致性，不能仅检查独立玩具图。
- 同适配器重复像素及松散／包往返精确一致。每个 Native／浏览器 RGBA8 通道（含法线）继续要求最大分量差 <=1。覆盖固定软件及明确记录的 GT 1030 Vulkan/DX12 相对 Chrome 路径；调查失败，不推广既有噪声验收范围。
- 着色器实现前冻结默认 256² 相对降采样 1024² 的高度／baseColor 平均误差限制。从 MAT-01 的 4/255 目标开始，依据现有节点输入及规定的形态半径映射确认可行性。单独记录高频和亚像素宽度压力，不能将默认失败重新标为压力。整数半径映射不承诺精确分辨率无关。
- 初始资源上限：2048² 不超过 24 个 pass、512 MiB 描述符峰值，现有全局安全限额不变。GT 1030 目标为 1K 冷渲染 <=10 s、五次热渲染中位数 1K <=1 s、2K <=4 s；固定软件分别为 <=60 s／20 s／80 s。这些暂定设计预算须在实现前冻结到计划。实际图超限时触发 PERF-MAT 测量及独立优化切片，不能增大预算。选定优化前先记录编译器保留全部中间资源时的估算。
- 保留固定灯光／相机的金属 PBR 视图，包含平面／球体、近景及重复平铺。消费者预览须读取 metallic 贴图；MAT-01 的纯介电视图不能验收此材质。保留真实人工决定及评审字节。保持原始及迁移材质回归、公开包消费、六项必需 CI 和配对文档。
