以 1024² 的 plain 和 varied 分别执行公开 material.mix／CLI；仅诊断配色设 warpColor=[1,0,0,1]、weftColor=[0,1,0,1]、backingColor=[0,0,1,1]、detailAmount=0，保留相同几何。baseColor 的 R/G 单调 sRGB 编码分别标识实际 GPU 可见经／纬权重，不用 CPU 计算高度或可见性。每个经线上交点（i+j 偶数），对其轴向整格 j/nWeft≤v<(j+1)/nWeft 内的每个像素行，取该经线横向占用≥0.5 的固定核心：abs(fract(u*nWarp)-0.5)≤(warpWidth-bevel)/2。分母是核心的像素宽度，分子是其中 R>G 的像素数；相等视为未赢得可见性。纬线上交点（奇数）对称地按列测量 G>R，核心使用 weftWidth 与 weftCount。记录整个瓦片全部扫描线的 min／median／max、交点数、扫描线数；不丢弃交点中心或端部。半占用核心排除固定抗锯齿边缘，不能据此声称整根纱线外轮廓不变。

目标：在边界内最大化四组（plain／varied × 经／纬）的最小比值，并使两预设最坏宽度缺损 1-min 至少减半；报告中位数与剩余收窄，不将数值改善视为彻底消除或人工接受。理想直边比值为 1。粗网格 underRatio={0.25,0.5,0.75} × crown={0,0.25,0.5,0.75,1}，含原始 0.5/0.5；对入围者保留真实默认颜色的 baseColor／normal／height 和同区域 256² 原分辨率裁剪。保持 relief=0.025、normalStrength=0.5；借助高度和法线检查上下凹陷仍可读，而非减弱法线掩盖轮廓。所有输出在忽略目录 tmp/mat03-revision/，不提交扫描／裁剪工具。

## 材质简述与坐标

一个不透明介电织物家族：规则平纹，以及具有不同轴密度／宽度、两种纱线颜色和显式种子纵向纹理的变化平纹。“变化”仍使用同一种交替组织，不是斜纹或第二套编织目录。经线沿图像 v（纵向），纬线沿 u（横向）；原点左上，u 向右、v 向下。一个归一化 UV 瓦片沿两轴重复。经纬数量均为偶数，以保持交叉相位周期。数量决定中心间距（1/count），宽度另以对应轴间距的比例控制。不承诺物理毫米或网格密度。

交点 (i,j) 在 (i+j) 为偶数时经线上、纬线下，奇数时相反。更改宽度、间距、颜色或种子不能交换此顺序。高度是零基准表面起伏，不是双面几何。输出 baseColor、roughness、metallic=0、height，以及仅从最终存储高度生成的 normal。间隙显示不透明暗色底布；排除 opacity、AO 和 displacement 输出。方向纹理体现在贴图中；当前法线／粗糙度通道不提供各向异性 BRDF。

## weave-pattern@1 提案（待目录／版本评审）

名称与 brick-pattern 对应，表示有界程序化图案。**版本 1 仅表示平纹**：一个不透明家族，可使用不等经纬数量和宽度；不含斜纹、组织目录、布料模拟、纤维几何、各向异性 BRDF 或通用抗锯齿。节点只生成结构场；纹理、颜色、粗糙度、高度缩放及法线仍由既有节点负责。

### 端口与参数

无输入。恰好一个输出 **value: Scalar**，default=None。[NodeContract](../crates/mixture-core/src/registry.rs) 有 `outputs: &'static [PortContract]` 和具名输出查找，元数据／边验证可以描述多个端口，但**不等于端到端多输出执行**：[lower.rs](../crates/mixture-core/src/compiler/lower.rs) 取 outputs.first()，按节点 ID 存一个 ResourceId，并按生产节点 ID 解析输入；[ComputePass](../crates/mixture-core/src/plan.rs) 只有一个 output/output_desc。提议使用 mode 参数、三个普通实例和一个共用 KernelId／WGSL，避免修改编译器／计划／资源模型。提议的最小集合为三个场：高度不能兼作占据率，否则重演胶囊失败；高度／覆盖也不能识别两种纱线颜色中哪种可见。把无关字段塞进 Color 会违反端口含义，且没有标量提取契约。

| 参数 | JSON 类型／闭区间域 | 提议默认值 |
|---|---|---|
| mode | 枚举：height、coverage、warp-share | height |
| warpCount、weftCount | 整数 token 4..32，**仅偶数** | 8、8 |
| warpWidth、weftWidth | Float 0.55..0.9，横向间距比例 | 0.7、0.7 |
| bevel | Float 0.02..0.12，按横向间距计的内侧占据羽化宽度 | 0.08 |
| crown | Float 0..1，抛物线与平方抛物线横截面的插值 | 0.5 |
| underRatio | Float 0.25..0.75，下／上层中心高度比 | 0.5 |

crown 是**已批准的轮廓控制**，已由上方节点决定冻结。家族／数量／宽度域保留已接受范围。所有参数都有默认值；已提供的值无论是否影响所选 mode、是否位于未使用分支，都须验证。奇数数量（包括 override）以 MIX_PARAMETER_INVALID_VALUE 拒绝，并提供节点 ID 和对应数量参数；不得取整。错误 JSON 类型、枚举大小写、非有限／越界值也使用 MIX_PARAMETER_INVALID_VALUE；未知键使用 MIX_PARAMETER_UNKNOWN。验证在 GPU 获取前完成。通用 Integer 范围不能表达偶数约束，需要节点语义验证。不提议随机变化，因此此确定性生成器**没有 seed 参数**；两个既有 fractal-noise@2 纹理节点仍须独立显式 u32 种子。后续增加随机结构需要另行评审契约／版本。

### 解析结构与连续性

以下为规范性**冻结节点契约**。按所述顺序以 f32 求值；命名归一化量限制在 [0,1]。定义 `F(t)=s*s*(3-2*s)`，`s=clamp(t,0,1)`。UV 原点左上、u 向右／v 向下。每轴 UV 先用 fract 包裹，再计算 `x=u*warpCount`、`y=v*weftCount`。令 `i=floor(x)`、`j=floor(y)`、`a=fract(x)-0.5`、`b=fract(y)-0.5`。经线沿 v，纬线沿 u。

每轴使用横向局部坐标 a（或 b）及宽度 w：

- 占据率 `A=F((w/2-abs(a))/bevel)`，只依赖横向距离，不依赖起伏或上下层序。
- `q=max(1-(2*a/w)*(2*a/w),0)`；`T=q*((1-crown)+crown*q)`。T 在纱线中心形成圆润峰值，无有限宽度平台；支撑域外 q=0。多项式避免三角函数／pow 差异，但不是精确椭圆。

分别记为 Aw/Tw 和 Af/Tf。定义整条经线的连续纵向起伏：`k=floor(y-0.5)`、`t=fract(y-0.5)`、`p=EuclideanMod(i+k,2)`；p=0 时 `Lw=1-F(t)`，否则 `Lw=F(t)`。纬线：`l=floor(x-0.5)`、`t'=fract(x-0.5)`、`p'=EuclideanMod(j+l,2)`；p'=0 时 `Lf=F(t')`，否则 `Lf=1-F(t')`。有符号整数 k/l 可为 -1；必须使用欧几里得奇偶性，不得使用负余数或未经检查的无符号转换。相邻区间连接值相同且一阶导数为零。

纱线高度 `Hw=Tw*(underRatio+(1-underRatio)*Lw)`、`Hf=Tf*(underRatio+(1-underRatio)*Lf)`。交叉中心 `((i+0.5)/warpCount,(j+0.5)/weftCount)` 的两个横向轮廓均为 1：i+j 偶数时 Hw=1、Hf=underRatio，奇数时相反；因此 relief>0 时中心上下层严格分离。偶数数量保证两轴起伏相位周期。横向单元边界的索引切换被零占据间隙隐藏；不存在纵向端帽。未被纬线覆盖的经线中心 Aw=1、Af=0，即使纱线下沉，覆盖仍为 1 且 Hw>=underRatio。这是与修订 4“覆盖=高度”的关键区别。

所有模式共用同一可见性计算：

- `e=bevel*(1-underRatio)>0`；`D=F((Hw-Hf+e)/(2*e))`。由于 e<(1-underRatio)，平滑深度选择器在交叉中心饱和到正确纱线。它避免硬 max 切换；过渡宽度仍须视觉评审。
- `C=Aw+(1-Aw)*Af`。`Vw=clamp(Aw*(1-Af*(1-D)),0,C)`；`Vf=C-Vw`。可见权重划分覆盖，而非高度。只有一条纱线时，无论其深度如何，该纱线份额都完整保留。
- `H=Vw*Hw+Vf*Hf`。根据 mode 返回归一化高度 H、独立覆盖 C 或条件经线份额 `S=Vw/C`（C=0 时为 0.5）。份额可在空白处跳变，但其覆盖加权贡献为零；要求可见权重／高度连续，不要求间隙中不可观察的选择器连续。未覆盖部分由不透明底布提供。

### 采样、存储与 ABI 草图

复用砖块固定 2×2 box 足迹：像素偏移 (0.25,0.25)、(0.75,0.25)、(0.25,0.75)、(0.75,0.75)，除以输出宽／高，按此顺序求值。分别累加 H、C、Vw。height 返回 sumH/4，coverage 返回 sumC/4；**warp-share 返回 sumVw/sumC**，sumC=0 时返回 0.5，而不是各采样份额的非加权均值。这样部分足迹内的平均可见占据在 half 存储前保持一致；独立 half 存储和后续混合仍引入舍入，必须验收。三个实例的几何参数及尺寸必须完全相同，夹具调用方解析一个参数包并复制；独立节点验证不强制跨实例相等。外部纹理由既有节点采样，因此不承诺联合四点积分或通用抗锯齿。

每个模式在 f32 求值及现有 half 转换后，以 rgba16float 存储 [value,0,0,1]。无打包次级通道、CPU 执行器、上传或隐式查找。同适配器重放须确定；f32 运算、除法、f16 存储及法线放大仍须 Native／浏览器 <=1/255 验收，覆盖 256／1024／2048 及 257×129。比较周期平移求值，不要求两侧边缘像素相同。不得在未测量边界时宣称 GPU 无缝，或任意小 relief 在 half 下溢后仍精确分离。

提议 uniform ABI 为 **48 字节**，三个 16 字节行（偏移单位字节）：

| 偏移 | 四个 word |
|---|---|
| 0 | u32 warpCount、u32 weftCount、u32 mode（height=0、coverage=1、warp-share=2）、u32 reserved=0 |
| 16 | f32 warpWidth、f32 weftWidth、f32 bevel、f32 crown |
| 32 | f32 underRatio、f32 reserved=0、f32 reserved=0、f32 reserved=0 |

提议一个 KernelId::WeavePattern 调用及一个 WGSL 文件，各 mode 共用采样 helper；8×8 dispatch，group 0 binding 0 为 uniform、binding 1 为输出存储纹理，尺寸来自输出纹理。确定性包含固定 mode 编码、无随机状态、固定求值／累加顺序、填充字清零及解析参数的常规规范计划哈希。本次不增加 ABI／kernel 代码。

## 保留修订 4 的控制、合成与精度

夹具指南负责精确调用方映射，JSON 负责默认值／用例。这些是普通调用方准备，不是 Core 执行的表达式或 MAT-04 可复用图 API。

颜色和粗糙度按上述规则与高度共用 C/D。金属度为零。轮廓／选择器种子显式为零且 variation=0；仅纹理种子随机化颜色／粗糙度，不改变 W/F/Q 或高度／法线。颜色仅影响 baseColor，粗糙度控制仅影响 roughness，法线强度仅影响 normal，relief 仅影响高度／法线。underRatio 通过 C/D 影响全部非金属度通道。宽度／数量控制保留独立几何含义，经线间距不得改变独立纬线轮廓，反之亦然。
