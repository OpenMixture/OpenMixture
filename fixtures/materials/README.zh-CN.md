# 材质夹具

[English](./README.md) | 简体中文

本目录为 PR-008 至 PR-010 引入的釉面陶瓷、类皮革和方向性木纹基准材质预留。M0 没有伪造基准或验收声明。

未来每种材质目录包含 `material.mix`、`README.md`、`acceptance.json`、`variants/`、`expected/` 和 `reports/`。关闭 M3 前，机器检查和人工视觉验收必须一致。

基准更新要求显式接受标志，必须拒绝在 CI 中运行，并产生可审查的修改前／修改后／差异证据；不暂存或提交文件。参阅[基准规则](../../AGENTS.zh-CN.md)和[M3 路线图](../../ROADMAP.zh-CN.md)。
