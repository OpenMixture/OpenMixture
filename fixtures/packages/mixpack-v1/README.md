# M6B-02 package design corpus

English | [简体中文](./README.zh-CN.md)

These are **design fixtures for an unimplemented Rust codec**, generated by [the standard-library experiment](../../../scripts/measure-package-formats.py). [cases.json](./cases.json) binds file hashes, sizes and expected future error codes. `valid.mixpack` contains the existing height fixture and a 2×2 linear RGBA8 resource; Python's independent standard tar reader recovers all entry bytes exactly.

Other files deliberately violate the [selected v1 contract](../../../docs/m6b-package-format.md). Do not extract them to disk. Expected codes are not claims of passing production rejection tests. M6B-03 must execute this corpus through the public Rust loader, plus boundary, source-integrity, closure, policy and lifetime cases required by the contract. No golden pixels are stored or changed here.
