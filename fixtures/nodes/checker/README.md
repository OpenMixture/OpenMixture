# Checker v1 reference fixture

English | [简体中文](./README.zh-CN.md)

This PR-004 fixture belongs to the fixed built-in probe, before the M2 node registry. See [the complete contract](../../../docs/builtin-checker.md).

- [checker-64.png](./checker-64.png): visually reviewed GPU-generated 64×64 preview.
- [checker-64.rgba](./checker-64.rgba): 16,384 tight RGBA8 bytes, top-left origin; the comparison baseline.
- [provenance.json](./provenance.json): pinned SwiftShader commit, platform, format, hashes, and initial review.

The source is the single [WGSL implementation](../../../crates/mixture-wgpu/shaders/nodes/checker.wgsl). Expected pixels were captured from SwiftShader, not generated by a CPU reference renderer. The image contains an 8×8 grid, black top-left, opaque alpha, and 2048 pixels of each color. Apple M5/Metal produced identical decoded bytes.

`cargo xtask gpu-smoke` compares against these bytes and writes candidate output, reports, and comparison evidence to ignored `tmp/gpu-smoke/`. It cannot overwrite this baseline. Changes require the [golden review policy](../../../AGENTS.md), including visual review; do not copy new output merely to make a test pass. The general `golden update` command remains unimplemented.

Focused tests also cover 1×1, 65×3, non-multiple workgroups, row padding, zero/oversized dimensions, budget failures, repeated render/drop, invalid shader/pipeline, destroyed devices, map failures, and PNG encoding/I/O. Ordinary tests are GPU-free; smoke explicitly enables the ignored GPU cases.

PR-007 [input.mix](./input.mix) and [cases.json](./cases.json) exercise the `checker` graph contract. Cases: `defaults`, `odd-size`, `one-cell`, `max-cells`, `colors`, `256-grid`. The manifest contains 6 valid GPU cases and 4 invalid source/override cases. Samples are fixed expected RGBA8 sentinels with explicit 0/1-code-value tolerance; they are not generated by a CPU graph evaluator. Invalid cases must fail before GPU acquisition.

The [contract](../../../docs/node-contracts.md) defines parameters/defaults/formulas; [graph rendering](../../../docs/graph-rendering.md) defines f32/f16 precision, channel encoding, and evidence. The pixel path uses [checker.wgsl](../../../crates/mixture-wgpu/shaders/nodes/checker.wgsl). `material-output` itself only maps resources; synthesized defaults use the constant kernel.

```bash
cargo xtask test-node checker
```

This command validates the fixture families without a GPU, then explicitly runs this node on the selected adapter. Local Metal and pinned SwiftShader results are linked from the rendering guide. Pixel goldens remain protected; this fixture command does not update them.
