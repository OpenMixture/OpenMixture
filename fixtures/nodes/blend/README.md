# blend v1 fixtures

English | [简体中文](./README.zh-CN.md)

PR-007 [input.mix](./input.mix) and [cases.json](./cases.json) exercise the `blend` graph contract. Cases: `defaults`, `multiply`, `screen`, `zero-opacity`, `zero-mask`, `half-mask`, `opacity-times-mask`, `default-mask`. The manifest contains 8 valid GPU cases and 3 invalid source/override cases. Samples are fixed expected RGBA8 sentinels with explicit 0/1-code-value tolerance; they are not generated by a CPU graph evaluator. Invalid cases must fail before GPU acquisition.

The [contract](../../../docs/node-contracts.md) defines parameters/defaults/formulas; [graph rendering](../../../docs/graph-rendering.md) defines f32/f16 precision, channel encoding, and evidence. The pixel path uses [blend.wgsl](../../../crates/mixture-wgpu/shaders/nodes/blend.wgsl). `material-output` itself only maps resources; synthesized defaults use the constant kernel.

```bash
cargo xtask test-node blend
```

This command validates the fixture families without a GPU, then explicitly runs this node on the selected adapter. Local Metal and pinned SwiftShader results are linked from the rendering guide. Pixel goldens remain protected; this fixture command does not update them.
