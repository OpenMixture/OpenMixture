# 砖块图案夹具

[English](./README.md) | 简体中文

MAT-01b 实现[版本化砖块契约](../../../docs/mat-01-structured-materials.zh-CN.md)。[源码](./input.mix)暴露所有参数。[用例](./cases.json)以字面内部／间隙哨兵验证对齐及错行单元、奇数矩形尺寸与单像素输出；默认及最大种子用例执行生产着色器。

Core 测试拒绝缺失／非法种子、不支持版本及奇数错行，包括原子覆盖后的情况；验证裁剪、参数身份和原始源码保留。GPU 测试还检查重复输出精确一致、种子改变单元幅度但保持可分辨间隙、零 variation 下种子无影响及退化尺寸。不使用量化后不足一个字节级的倒角像素推断占用范围。

使用显式适配器策略运行 `cargo xtask test-node brick-pattern`。固定软件矩阵及已有材质回归继续必需。这些节点夹具不证明 MAT-01 材质或跨端验收，冻结材质验收契约仍独立执行。
